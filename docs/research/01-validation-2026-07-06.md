## 3. /review — adversarial

**Real bug found & fixed:** Format readers (gguf/safetensors/npy) **panic**
on hostile dims (2⁶³ → negative int; n·bytesize wraps to 0 → slips past the
size check → `tensor.New` panicked). Reproduced with a hand-built
GGUF file → panic reproduced. Fix: dims + running product capped at 1<<40
before allocation → **new invariant §V15 UNTRUSTED-IO** + regression test
(2⁶³/2⁶²/over-cap). All three readers hardened, green.
