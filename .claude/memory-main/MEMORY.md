- [Self-policing guard pattern](self-policing-guard-pattern.md) — a guard that reads the table it checks only proves the table equals itself; a guard written as a CONDITION (`ok && t.Ndim()==2`) is not a guard at all — it skips the very inputs it exists to reject (§B77); two guards on the same data must SHARE one predicate, and neither side may be stricter; derive ground truth from the implementation (AST/PC, not the declaration), break it on purpose on the HARDEST case and confirm red, floor the sweep against vacuity, and make reflection-based binding error rather than no-op. A guard can also stop measuring long after it was written (intercepted upstream, mislabelled arm, printed-not-asserted, measuring the race detector, comparing bytes git rewrote) — and thresholds calibrated on this M2 INVERT on shared CI runners.
