## §V — verification invariants

| id | tag | invariant |
| --- | --- | --- |
| V1 | PARITY | ∀ op → golden test vs NumPy/torch within §R6 tol (f64 rtol 1e-12, f32 rtol 1e-5). missing golden → generate reproducibly + commit. |
| V2 | GRAD | ∀ differentiable op → numeric gradient check (central finite diff) under rel 1e-4. |
| V3 | CROSS | accel backend result == Pure-Go reference within backend tol defined by V11 (exact bit-match ⊥ required — SIMD/parallel reorders sums). |
| V4 | PLATFORM | CI green ∀ {macOS, Windows, Linux} × {Pure-Go fallback + available accel}. missing accel → skip w/ log, ⊥ silent pass. |
| V5 | BENCH | ∀ optimized op → benchmark + baseline number recorded. regression breaks CI. |
| V6 | PROP | property-based tests (shape algebra, linearity, associativity where math-guaranteed). |
| V7 | CGO | ⊥ cgo in ship path without green optimized Pure-Go ref + committed benchmark over §C.thr. `CGO_ENABLED=0` green everywhere. |
| V8 | STABLE | public API changes only via documented deprecation path. |
| V9 | TRUTH | Pure-Go reference backend = source of numeric truth; accel validated against it (⊥ vice versa). |
| V10 | ACCUM | reduction & GEMM accumulation → f32 inputs accumulate in f64 (∨ Kahan) unless §R justifies else. parallel/goroutine reduction order documented; non-determinism only w/ §R-justified tol. guards non-associative FP [B6]. |
| V11 | CROSSTOL | ∀ accel op → backend tol documented per op, rtol scales w/ reduction length K (⊥ single fixed rtol). defines V3. established: elementwise (T11) & blocked-GEMM (T12/T12b) = exact (tol 0, same accum order); metal f32 GEMM (T20) = rtol(K)=1e-6·√K (MPS f32 accum + reorder) [B5]. |
| V12 | EDGE | ∀ op → documented policy for NaN/Inf (IEEE-754 propagate), empty tensor, zero-dim, non-contiguous view. golden ! include edge cases [B9]. |
| V13 | GOLDEN-REPRO | ∀ golden file → record generating env (lib+version, dtype, seed, shape) in sidecar. regeneration deterministic. guards V1 reproducibility [B8]. |
| V14 | BACKEND-EXEC | `Backend`/`Kernel` interface ! define execution/sync model (sync default; async accel exposes explicit `Synchronize()`) at T5, before any accel/T20. adding GPU ⊥ break V8 [B7]. |
| V15 | UNTRUSTED-IO | ∀ format reader (gguf/safetensors/npy) on hostile input → return error, NEVER panic/OOM/overflow. all length/dim/nesting claims capped BEFORE alloc (header ≤ cap, numel ≤ cap, array-depth ≤ 64, grow ⊥ pre-alloc-from-claim). GUARDED BY native fuzz tests (FuzzLoad/FuzzRead/FuzzRoundTrip) + hostile-input regressions [B28,B31,B32]. |
| V16 | VALIDATION-LADDER | ∀ ALGORITHM impl → 2 tiers, both required. tier1 = bit/tol parity vs a reference LIB (torch/sklearn/ggml-py/…). tier2 (FINAL authority) = the defining SCIENTIFIC paper/source (arXiv/DOI/canonical textbook) — implemented formula matches the paper's equation, cited in §R. tier1 alone ⊥ sufficient. FILE FORMATS have no paper → their reference SPEC/impl IS the definitional source (stated, ⊥ invent a paper). paper-tier status tracked per algorithm in §R. |
| V17 | DOCS | ∀ exported package & top-level symbol → godoc present, dual-audience (professional: math + §R paper-cite; layperson: plain what/why/when). ∀ user-facing package → runnable `Example` fns at ≥3 levels: trivial, realistic use-case, embedded-in-bigger-pipeline. examples live in `example_test.go`, verified by `// Output:` under `go test` (∴ docs ⊥ rot — CI runs them). new public API ⊥ "done" until its godoc + examples exist (part of task DoD). guards C10. |
| V18 | AUTOSELECT | backend.Default() = highest-preference REGISTERED backend along the descending-performance order (default cuda>metal>vulkan>cpu, §R46), else the reference — the guaranteed final fallback, ALWAYS present. accel backends Register in init() ONLY when their device is detected (§V4 — ⊥ silent claim of an absent device). selection by preference order, ⊥ by registration/import order. order overridable via SetPreference; unknown names skipped safely. NewContext & autograd.NewTape use Default → building with an accel tag routes work to GPU w/ NO code change. GPU-first default justified by benchmark, ⊥ aspiration (§R46). |
| V19 | DOCS-GATE | internal/apicheck walks every public pkg via go/ast (parses SOURCE, ⊥ imports the pkgs → build-tagged cgo backends checked too) and FAILS on: (a) any exported symbol (func/type/method/const/var) lacking a godoc comment, incl. any exported STRUCT FIELD lacking a doc/inline comment (fields = public-facing API, "docs for everything public facing"); (b) any user-facing pkg with no `Example`; (c) any exported user-facing TYPE not shown in a runnable Example — coverage credited if the Type name, its `New<Type>` ctor, OR an `ExampleType`/`ExampleType_*` appears in any Example (bodies inspected via ast). section comments before a grouped const/var attach as doc to the first spec only → each grouped one-liner needs its own comment. (d) any exported METHOD on a user-facing type not exercised in any runnable Example — credited if the method name is CALLED in any Example body (ast-inspected selector calls) or an ExampleType_Method exists. per-type AND per-method rules each have a JUSTIFIED allowlist (typeExampleExempt / methodExampleExempt: interfaces, functional-option/callback func types, enums, config structs, fixture-heavy models, trivial accessors covered by the type example = "where meaningful"). runs as a normal test (`go test ./...`) + `make apicheck`; in `all`/`ci`. = mechanical enforcement of C10/V17/C13 BEFORE commit/push. exempts internal/* + backend impl subpkgs (blank-import registration, not public surface). guards C13. |
| V20 | OP-PARAMS-TYPED | `backend.Attrs` is a sealed interface (`interface{ opAttrs() }`), never `map[string]any`; every op's params = a concrete struct impl (§I6/§C14/ADR-0014). guard test internal/apicheck TestNoStringKeyedAttrs greps the tree → FAILS if the accessor pattern (`attrs.Int(`/`.Bool(`/`.Float(`/`.Ints(` on an Attrs) or an `Attrs map[string]` decl reappears. defaults single-sourced in each struct's `WithDefaults` (kernel+VJP call it → ⊥ drift). construction wrong-field/type = compile error. in `all`/`ci`. |
| V21 | NO-MAGIC-STRINGS | internal/apicheck TestNoMagicBackendNameStrings walks every .go via go/ast (string BasicLits only → comments/import-paths ignored) & FAILS on any backend-name literal ("cpu"/"ref"/"metal"/"cuda"/"vulkan") outside the allowlist {backend/names.go = the Name enum def, tensor/device.go = the DeviceKind Stringer}. enforces §C15/ADR-0015: backends referenced by typed backend.Name constants, ⊥ bare literals. in `all`/`ci`. |
| V22 | BOTTLENECK-MEASURED | a "the floor/bottleneck is X" attribution is a MEASURABLE claim, ⊥ an assumption — before recording it as fact OR building an optimization on it, A/B it by forcing the suspected cost OFF (e.g. force-disable the copy / the alloc / the dispatch) and comparing same-session medians. If removing X ⊥ moves the number, X is not the bottleneck. Prevents §B42-class waste (3 notes asserted a memcpy floor never measured; zero-copy built on it → 0 delta → reverted). |
| V23 | CGO0-COMPILES-TESTS | the pure-Go gate runs `CGO_ENABLED=0 go vet ./...` (or `go test`), ⊥ `go build` alone — build skips _test.go files, so an untagged test file referencing cgo-only symbols passes build but breaks the suite (§B45). every cgo-backend test file carries its build tag; the gate must compile tests to enforce it |
| V24 | SWEEP-BUDGET+EXIT | the full sweep runs `go test` with `-timeout 1800s` (llamagpu's trained-model suite legitimately exceeds the 600s default — §B46: 670s green vs FAIL at the default) AND checks the exit code UN-piped (`cmd > file; echo $?` — a trailing `\| grep \| tail` masks FAIL with exit 0, the §T447 lesson violated AGAIN in §T515). a sweep 'green' claim without both is void |
| V25 | KERNELS-SEE-NO-RECORDER | backend.Execute strips the tape recorder from the ctx handed to kernels (recording happens ONCE, at the Execute choke point, after the kernel returns) — an in-kernel re-dispatch (ref fallback, ADR-0008 cpu routing) can therefore NEVER double-record an op and double its gradients (§B49 live occurrence, §T537's 46 latent sites, §T538 structural enforcement). the per-site .WithRecorder(nil) strips remain as documentation but are no longer load-bearing |
| V26 | CI-SKIP FAILS OPEN | the docs-only change detector (internal/cichange) may skip CI ONLY on a POSITIVE proof that no code changed — every uncertain case (parse error, unknown file class, missing/unavailable base revision, workflow-file change, non-Go non-doc file, added/deleted files that are not pure docs) classifies as CODE and runs the full pipeline. asserted by unit tests per case. skipping is an optimization, never a correctness decision |
| V27 | SELECTOR-SOUNDNESS-POST-PUSH-VALIDATED | After EVERY push the loop validates the CI selector's choice for the pushed range: an independent ORACLE set is computed via the Go toolchain (`go list -deps -test` reverse closure — build-tag-aware, the compiler's own truth) and compared against the selector output. selected ⊉ oracle = UNDER-SELECTION → release-blocking bug: §B row, immediate full-suite run, selector fix before the next selective push. selected ⊃ oracle = over-selection → allowed (sound) but recorded as an efficiency delta (excess pkg count) in the fire report. `all`/`none` verdicts validate trivially (`none` requires oracle=∅) |
| V28 | EXECUTE-SCREENS-ATTRS | backend.Execute rejects a NON-nil Attrs whose concrete type is not the one its op declares, BEFORE kernel resolution, naming op+got+want. this is what makes the codebase-wide `pa, _ := attrs.(backend.XAttrs)` idiom safe: discarding the `ok` is correct for nil (the convention for parameterless ops and ops relying on defaults) but a swallowed type MISMATCH hands the kernel a ZERO Attrs and returns a WRONG ANSWER with err==nil (§B69: OpSum+ConcatAttrs → scalar 28 instead of [6 22]). the op→type table is kept honest by a guard that NEVER READS IT — it derives ground truth from the kernels themselves (PC→function→ref-package AST→the assertions the kernel actually performs, following attrs into package-level helpers) and cross-examines Execute's public behaviour. a guard that read the table would only prove the table equals itself |
| V29 | FOREIGN-PARSER-HOSTILE-GATED | every reader of a foreign format (npy, npz, safetensors, pytorch, gguf) rejects a malformed file with a CLEAN ERROR — never a panic, and never a wrong-but-nil-error tensor. concretely: shape products use the division-BEFORE-multiply guard (a post-multiply cap wraps and lets a hostile header through), negative dims are rejected, and no opcode/field parser indexes a stack or buffer without an emptiness check. each reader carries a hostile_test.go, and any fuzz target must actually REACH the parser under test — §B70's FuzzLoad fuzzed the zip container, so the pickle interpreter behind it was effectively unreachable (966k execs / 6 interesting) until a target taking raw inner bytes replaced it (5.77M / 104) |
| V30 | SPECIAL-TOKENS-ARE-A-TRUST-BOUNDARY | a control/special token is minted ONLY from the specials-parsing path (EncodeSpecial), NEVER from untrusted text through plain Encode. this is a security property, not an ergonomic one: the chat template emits its markers as literal text, so if untrusted user content could encode to the same control ids it would forge conversation structure. two distinct paths must be closed and BOTH have been live (§B72) — the marker-matching pre-split (do it only on the trusted path) AND the segmentation algorithms themselves, since GGUF stores control tokens inside the main vocabulary and Unigram's Viterbi / WordPiece's MaxMatch search all of it. any new tokenizer or new segmentation path must gate on both; the injection case is a REQUIRED test, and it must be verified by mutation (rebuild the naive always-parse design and confirm the gate fails) |
| V31 | ONE-DECODE-PATH-PER-ARCH | a model architecture's per-block features (biases, QK-norm, the Granite scalars) are applied in ONE place that every decode entry point routes through — DecodeStep, StreamStep and SelfExtendForward share a block stack whose only pluggable part is the attention core. duplicated decode logic drifts silently and asymmetrically (§B75: streaming dropped all six hooks while the normal path kept them, so the SAME model+prompt gave different tokens through different entry points, with no error). where a copy still exists it must be named in godoc and pinned by a cross-path equivalence test that (a) compares TOKENS not just logits, (b) uses NONZERO values for every feature per §B68, and (c) includes a feature-free control that passes in BOTH the broken and fixed states — without that control a failing gate cannot distinguish a real drift from a broken harness |
| V32 | LOSSFREE-MOE-GATE | enabling auxiliary-loss-free MoE routing uses the paper's affinity exactly: s=sigmoid(routerLogit), TopK ranks s+b, and combine weights derive from s with b ABSENT (renormalization after selection allowed). the unoptioned Mixtral route remains softmax. required gates: a decisive case where sigmoid(logit)+b and logit+b select different experts, integrated Forward vs sigmoid reference, ForwardDecode equivalence, and router finite-difference gradcheck. bias is control state outside Params/autograd and updates only through the explicit per-batch sign rule (§B87/R242). |
| V33 | EAGLE-LOSS-PAPER-EXACT | EagleLoss feature regression = mean SmoothL1_beta=1(pred,next), then +0.1*token CE; MSE proxy forbidden. Required decisive hand-reference includes abs(d)>1 linear branch, full head finite-diff grad, arbitrary-head lossless generation. (§B90/R256). |
| V34 | QGALORE-PAPER-EXACT | default QGaLore = GaLore subspace + block-wise INT8 moments + packed affine INT4 projection + parameter-local adaptive SVD gap (official threshold/multiplier/window 0.4/2/5) + block-wise affine INT8 weights re-quantized by unbiased stochastic rounding. QuantBits 0 or 64 disables ALL four deltas and must remain bit-identical to GaLore across both projection sides and full rank. Required decisive gates: packed code/size/error bound, stable-subspace SVD-count reduction, both rounding branches + integrated weight-store mirror, convergence, deterministic seed. No end-to-end weight-memory claim while public Tensor keeps a float execution mirror (§B92/R259). |
| V35 | APOLLO-SEED-ONLY-PROJECTION | APOLLO persistent matrix state = two-word projection seed + low-rank moments + limiter scalar; retaining the O(r·min(m,n)) Gaussian matrix is forbidden. P regenerates bit-identically from the seed on every use and changes only when Gap replaces that seed; reseeding preserves moment buffers. Required gates cover both projection sides, seed regeneration equality, Gap reseed difference, state shape, convergence and trajectory determinism (§B94/R258). |
| V36 | SPEC-TABLE-INTEGRITY | SPEC.md §T/§B/§R/§V ids UNIQUE (monotonic, ⊥ reuse — B96) & ∀ §T row lives INSIDE the single contiguous §T GFM table (⊥ headerless fragment in another section — B97: EOF-appends after §B fed the 4-col §B table 6-col rows, 148 tasks GitHub-render-mangled, mdlint 166× table-ragged) & §T = LAST section of SPEC.md so append-at-EOF stays structurally correct & ∀ SPEC/worker-spec table mdlint-green. enforced: internal/mdlint repo test (already CI-side) + T886 spec-lint (id-uniqueness + §T-membership scan). [B96,B97] |
| V37 | PREDICT-WIDTH-GUARDED | every classic estimator predict-family method (Predict / PredictProba / DecisionFunction) rejects an input row whose width ≠ the feature count recorded at Fit with a CLEAN error naming row index, got width, want width — NEVER a panic and NEVER a silent truncation that drops or mispredicts on the surviving features. two live failure modes closed: §B100 LinearRegression.Predict ranged over the INPUT ROW not m.Coef, so a 3-feat model on {2,1} silently returned 4.125 (dropped coef[2]·x[2], err==nil); §B101 SVC PANICKED (index-out-of-range) while GBM SILENTLY MISPREDICTED (shallow splits still traverse the surviving features and return a plausible wrong number). the guard lives at ONE site per estimator (SVC.Predict routes through the guarded DecisionFunction) and is proven non-vacuous by stripping it and confirming predict_width_test.go goes red (silent-drop / silent-accept / index-panic), green restored. KNN/tree/forest/GaussianNB already carried this guard; the outliers now match. |
| V38 | CROSS-IMPL-PERF-CLAIM-IS-MEASURED | a performance claim comparing GoAI to an external incumbent (X vs tiktoken/torch/sklearn/llama.cpp …) is MEASURED, never asserted — both sides run on a byte-identical input and identical vocab/config, output equality is cross-checked (same token count / same result within tol) as the fairness anchor, the incumbent version is recorded (§V13), and the comparison is reproducible from a committed companion (script ∨ benchmark). A doc comment or table stating "measured N vs M" with no committed measurement path is a §C3 violation (§B102: BenchmarkGPT2Encode asserted 23 vs 20 MB/s citing a 216511-token count from a different corpus; the real measured numbers are 28.2 vs 18.8 MB/s encode / 470 vs 392 decode at 237208-token parity). Where the incumbent runs through a foreign-language binding, the marshalling cost it imposes on a real caller is part of the honest number, but the framing must say so (a library-delivery win is not a claim that one core out-computes the other in isolation). |
| V39 | NO-DANGLING-STRONG-REFS | ∀ id in a §T cites cell, a CHANGELOG task ref, ∨ a §B guard chain → resolves to a defined entity. enforced: internal/docgraph TestNoDanglingStrongRefs (strong edge classes cites/records/guards over the real corpus). weak prose refs stay advisory — V1024-class lookalikes (vocab-size tokens), pre-rewrite ids (T96/R269) & rebased-away commit SHAs are TOLERATED, ⊥ spec bugs. prevents B113 recurrence (V27-in-§T fragment, T765 changelog-only booking) |
| V40 | CICHANGE-ALWAYSRUN-PARITY | the -run path (Run(), what CI executes — ci.yml) and the -impact path (Impact()) MUST apply the IDENTICAL always-run set (§T893 whole-tree meta-tests the reverse import closure can't reach) to every NON-EMPTY selection, and NEITHER to an empty one (docs-only/all-ignored → zero-runner, §C16 EXC2).
