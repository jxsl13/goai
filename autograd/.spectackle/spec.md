## PERMUTATION-BAND-TWO-GATES-001
WHEN a permutation nest is split into parallel bands, the its test suite SHALL gate it with BOTH a value comparison against the definition and a -race run, over at least 1 shape clearing the fan-out work gate.

Rationale: What makes a permutation safe to split is that every destination cell depends on nothing but its own source cell. That same property makes a band OVERLAP invisible to a value comparison: the intruding band writes exactly the value the owning band would have written, so the result stays correct and only the concurrent unsynchronized write remains. Measured on the transpose VJP, a mutation starting each band one tile early passed the value check and was caught only by -race. The converse also holds: a band that SKIPS rows, or one that reads the wrong source cell, produces wrong values with no concurrent access at all, so -race is silent and only the value comparison fails. Three such mutations were red on values and green on -race. Neither test subsumes the other. Two corollaries. Size every fixture above the work gate, or both arms run serially and no banding mistake can fail at all. And build the comparison so an unwritten cell is distinguishable: a fresh zeroed destination plus all-nonzero source values carries its own sentinel and needs no prefill. Folded into the PS3056 guidance so it reaches whoever applies the check.

## A-FANNING-FUNCTION-MAY-STILL-HAVE-A-SERIAL-LOOP-001
WHEN looking for unused parallelism in a function that already calls a fan-out helper, the reviewer SHALL check every OTHER nest in it, because the checks that hunt unused parallelism suppress a function that fans out anywhere and that suppression hides the most valuable case.

Rationale: Measured twice, both large. The KAN forward fanned out buildBasis and left fusedSpline serial, which was 84 percent of the layer: banding it went 67.28 to 10.90 ms, a 6.2x. The eigendecomposition adjoint fanned out its first two n-cubed products and left the triangular third serial: banding it, plus mirroring the intermediate that loop reads down its columns, went 18.63 to 8.17 ms at n=256 with EighVJP_128 minus 46.0 percent and CholeskyVJP flat as a control. ATTRIBUTED: the banding is about 2x of that and the transposed mirror about 15 percent, so both are real and the parallelism is the larger half. A function that fans out has already proven the transform is available to it, which is exactly why the leftover loop is worth looking for. THE TRIANGULAR LOOP IS SAFE TO BAND because index i writes (i,j) and (j,i) for j at least i, so two different i values cannot write the same cell - a clash would force them equal. Bit-identical: each entry keeps its own ascending-a accumulation. Encoded as perfscan PS3063, 5 candidates tree-wide, which also had to learn to see writes made through a SETTER CALL rather than an index expression - the eigh adjoint writes its whole result through SetF64, so a walk that looked only for index expressions found no writes and concluded nothing.
