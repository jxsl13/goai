                       create_additions: false, allow_nan: false)

reject_nonfinite! branches on Float, Hash, and Array. Float#finite? is available on
the pinned Ruby. Hash values and array members recurse with deterministic diagnostic
paths. JSON parsing yields only these containers and JSON primitives, so no valid
parsed branch is missed. AllocationSites::Invalid raised by the recursive check is
not swallowed by the JSON::ParserError rescue. The committed tests cover finite
floats, root +/- overflow, nested +/- overflow, diagnostic paths, and downstream
