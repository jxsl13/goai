## Concrete defects

### 1. Binary mutation during the last invocation is accepted

`run.rb:127` hashes a binary only immediately before an invocation. It never
checks the hash after `Open3.capture3` and never performs a final sweep before
marking the manifest complete at `run.rb:152-155`.

The synthetic candidate binary changed its own file during its seventh and
last pilot invocation, emitted a fully valid benchmark fixture, and exited
successfully. The runner accepted the campaign and wrote `status: complete`.
An earlier self-mutation was correctly detected before that binary's next
invocation, which isolates the defect to the missing post/final check rather
than the fixture.

This violates binary-change detection and permits a completed campaign whose
measured executable does not match the hash in the manifest. Re-hash the
binary immediately after every subprocess and reject before parsing/retaining
the result; a final sweep is also a useful defense.

### 2. Contradictory extra host/package headers are accepted

`run.rb:34-37` requires one copy of each expected exact header but does not
reject another header of the same family with a different value. Each of the
following was independently appended to otherwise valid output and accepted:

- `goos: linux`
- `goarch: amd64`
- `cpu: Other CPU`
- `pkg: example.invalid/other`

Thus output can simultaneously claim the required Apple M2 Pro/darwin/arm64
package and a contradictory host or package. Validate that there is exactly
one total line for each header prefix and that its value is the expected one.
The existing benchmark-name suffix check did reject a GOMAXPROCS mismatch.

### 3. The actual inherited subprocess environment is not fully retained

`Open3.capture3` at `run.rb:133` inherits the runner process environment.
However, the manifest records only `GOGC`, `GOMEMLIMIT`, `GODEBUG`, and
`GOTRACEBACK` at `run.rb:120`, while each invocation records only the explicit
`GOMAXPROCS` overlay from `run.rb:130,136`.

A synthetic sentinel was visible to and required by every child process, but
was absent from both the manifest and invocation JSON. The frozen gate says to
record the full environment before running, so the retained evidence cannot
reconstruct the actual subprocess environment. A robust fix is to run the
benchmark under a deliberately controlled complete environment and record
that exact environment, avoiding accidental persistence of unrelated secrets.
